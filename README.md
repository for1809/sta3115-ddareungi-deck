# Where Do All the Ddareungi Go?

Final talk deck for STA3115 Exploratory Data Analysis (Yonsei University, Fall 2026), Group 1.

Open the deck: https://for1809.github.io/sta3115-ddareungi-deck/

Photos: Wikimedia Commons (*Youngjin, CC BY-SA 3.0; Sarang, public domain). Data: Seoul Open Data (Seoul Bike trips 2024 and 2025), KMA hourly weather, Seoul 1:5,000 digital topographic map.
